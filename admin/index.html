1. GitHub bağlantısı

Anahtar: GitHub → Settings → Developer settings → Fine-grained tokens. Yalnızca bu depoyu seç, "Contents: Read and write" izni ver. Anahtar sadece bu tarayıcıda saklanır, kimseyle paylaşma. Bu sayfayı herkes açabilir ama anahtar olmadan hiçbir şeyi değiştiremez.
